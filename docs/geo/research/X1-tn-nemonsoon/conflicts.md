# X1: real disagreements between our sources

**K1: Tamil Nadu's normal summer (June-September) share.** S03 (2023 report): "only about 36% (328.5 mm)". S01 (2025 report): "only about 47% (428.9 mm)". 428.9 mm is exactly the 2025 *actual* October-December rain for Tamil Nadu in S01's own Table-4, and 36% fits the arithmetic (328.5 + 442.8 = 771.3 mm, 83.7% of the year; the other 150.1 mm, 16.3%, is January-May). So S01's sentence looks like a mis-paste. The Short uses neither figure. (method/shares_output.txt)

**K2: S01's list of "normal" October-December rainfall.** S01 Background lists "TN-448.9 mm, KER-388.3 mm, CAP-394.7 mm, RYS-314.7 mm, SIK-188.5 mm". Table-4 of the same report gives those numbers (except TN) as 2025 *actuals* (CAP 394.7, RYS 314.7, SIK 188.5, KER 388.3; TN actual 428.9); the true normals are CAP 322.9, RYS 236.4, TN 442.8, SIK 199.0, KER 491.9. S03's equivalent paragraph prints TN 442.8 mm, which matches Table-4. The 448.9 looks like a typo for 442.8 (the independent check agrees). We use only the 442.8 mm and 48% values.

No disagreement found on: 48% (S01, S02, S03), the 20 October onset, the wind reversal wording, the Bay of Bengal systems.
