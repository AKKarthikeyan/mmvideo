# Syllabi

Exam syllabi we map videos and carousels to. Each syllabus has a readable `.md` (scheme, papers, full topic list,
source) and a `.json` topic tree with stable ids, so a script or an episode package can tag which topics a video covers
(for example `"syllabus": ["rbi-gb-2025/gen/gfm/c8"]` for ratio analysis).

| Syllabus | Files | Source |
| --- | --- | --- |
| RBI Grade 'B' (DR) 2025: General, DEPR, DSIM | `rbi_grade_b_2025.md`, `rbi_grade_b_2025.json` | RBI Services Board, Advt. RBISB/DA/03/2025-26 |

Adding a syllabus: copy the official text faithfully (don't paraphrase topics away), note the notice number and the
pages it came from, and keep ids stable once videos reference them; add new ids rather than renumbering.
