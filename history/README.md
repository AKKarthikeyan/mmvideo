# History videos (Indica Atlas)

Remotion package for Indica Atlas history visuals. Every frame and every sound is generated by code; there are no stock images.

| Composition | Size | What it is |
|---|---|---|
| `IndicaChronicle` | 1920×1080 | Chronicle long-form: 5 chapters timed to a beat grid, with a soundtrack generated by code |
| `IndicaChronicleVertical` | 1080×1920 | The same chronicle laid out vertically. **Format preview only**: a publishable Short must be its own Reveal Loop script (`../docs/SHORTS_FORMAT.md`) and pass `scripts/shorts_check.py` |
| `IndicaChronicleSquare` | 1080×1080 | The same chronicle laid out for a 1:1 feed post |
| `IndicaEmpireMap` | 1920×1080 | Parchment empire map: ink coastline, rivers, spread from the capital, year counter, scale bar |
| `IndicaMonumentSketch` | 1920×1080 | Pen-drawn monument with washes, dot shading, palms and people |

## Run
```
cd history
npm install
npm run score       # writes public/chronicle-score.wav (generated, so git ignores it)
npm run studio
npx remotion render src/index.ts IndicaChronicle ../out/history/IndicaChronicle.mp4
```

## The chronicle format
- **One file drives picture and sound:** `src/scenes/chronicle/chronicle.json` holds each chapter's dynasty, dates, keyword, caption, BPM, look (`paper` or `gold`), colour, border motif, drawing and instrument. The on-screen source line is there too.
- **Timing:** each chapter is 16 beats long, and the tempo rises with the centuries (72 → 120 BPM). Drawings, keywords, each caption word and the year counter all land on beats.
- **On-screen frame:** a vermilion chapter seal (top-left), the dynasty name in vertical text (right), and a scroll timeline with a year counter (bottom).
- **Transitions:** a seal stamps down with a screen shake. In the score, a big drum and a temple bell land on the same frame.
- **Score (`scripts/make-score.mjs`):** raga Bhupali over a tanpura drone. The lead instrument changes each chapter (flute → veena → sitar → bronze bells → orchestra), over tabla-like percussion.
- **Layouts:** `src/scenes/chronicle/layout.ts` picks the 16:9, 9:16 or 1:1 layout automatically from the composition size.
- **Library:** border motifs (`motifs.tsx`) are circles, lotus, vine, steps and jaali. Drawings (`drawings.ts`) are greatBath, pillar, shrine, vimana and dome.

## Rules from this repo that apply
- Show the source on screen, and label anything illustrative as illustrative.
- The Mauryan extent in `IndicaEmpireMap` is approximate. Replace it with a sourced shapefile before publishing.
- Check every date against a source before release.
