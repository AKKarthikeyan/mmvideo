# Jio IPO film: photo manifest (20 Oct 2026)

All photos are from Wikimedia Commons; licence, author and file page read from the Commons API (extmetadata) on 20 Oct 2026.
Originals (>=1600 px wide where the source had it, max 2000 px thumbs otherwise) are in `src_dl/`, metadata in `src_dl/_meta.json`.
Per photo: `NAME.jpg` = clean JPEG (max 2400 px wide, cropped where noted), `NAME_print.jpg` = A01-style archive-print tone
(warm monochrome via the `tone()` function of tools/prep_media.py; use with PhotoPrint), `NAME_sticker.png` = alpha cut-out
with baked white sticker border (same method as A01's candy box) for use with Sticker. Colour use: the clean JPEG.

Credit line is mandatory.
- Nothing here is non-commercial, no-derivatives or "fair use". No Commons page for these files carries a personality-rights warning (checked the Restrictions field).
- Location caveats: several fibre / data-centre / climber / antenna photos are not from India (USA, Chile, Finland, Austria, Germany, Poland, Japan, Philippines, Athens); they are generic infrastructure. Do not caption them as India. India-located files are marked "India" or the state in the description.
- Brands: every file was looked at; none shows a legible Jio / Airtel / Vi / BSNL / company logo or sign (two towers sourced from files titled "BSNL 4G" show no logo at full size; the BSNL / Vodafone-titled exchange, customer-centre, tower files were rejected or not used). Small incidental text remains in: crowd_dumdum_platform (railway station name board "Dum Dum Jn"), platform_mumbai_suburban (railway names on carriages), hand_phone_scroll_torso (decorative phone-case characters), kiosk_phone_accessories (generic "Mobile phone accessories" wording on a UK kiosk, no network brand), street_bangalore_rickshaw (tiny unreadable stall signage). Camera/phone shapes are generic.
- People: crowds, backs, hands, tiny distant figures. crowd_phones_row shows a row of identifiable seated conference attendees (faces visible, CC BY 4.0, no personality-rights note): use briefly, background only, or skip. technician_junction_box_india is a side/back view of a worker.
- Sticker cut-outs are mechanical: antennas_horn_relay_sticker has a ragged lower lattice; tower_in_todabhim_top_sticker is clean; rupee_coin_ten_sticker is a circle crop of a slightly soft photo.

## Gaps / not covered
- Prepaid recharge / SIM card as a real photo without a logo: none found on Commons (every real SIM photo carries a network brand or a hacker-event logo). Use `sim_sizes_graphic_sticker.png` (generic SIM chip graphic, CC0) or code-drawn cards.
- Mobile shop counter or recharge kiosk in India: the only Indian shop photos are CC BY-SA and show shop signage / branded phones (rejected). `kiosk_phone_accessories` (UK, CC BY) is a generic stand-in; otherwise build from type.
- Tower climbers: only non-India, mostly side views (USDA, USACE). Faces visible in other USDA frames (not used).
- Hand holding a phone: no Indian hand shots under CC BY/CC0; the three included are generic.
- Rejected on sight (brand or person): BSNL exchange / customer centre files, Takoradi/Oxfam/Tver shop photos, the two cable-drum shots with printed manufacturer text, FAFL "Guiding New Fiber" truck, Colaba repair kiosk (signage + personality note), the Vendor Using Mobile Phone haat photo (Commons page has a personality-rights note), Instagram-screen and Apple-logo phone shots.
