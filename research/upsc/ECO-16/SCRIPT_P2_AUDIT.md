**Arithmetic redone.**
- Geometric series (A04): 100 + 80 + 64 + ... = 100 / (1 - 0.8) = 500. Loans 80 + 64 + ... = 80 / 0.2 = 400. Reserves 0.2 x 500 = 100. Round 1: reserve 20, loan 80. Round 2: 20% of 80 = 16, loan 80 - 16 = 64. Cumulative required reserve 20 + 16 = 36 (matches NCERT Table 3.2 round 2, 20% of 180 = 36; loan 100 - 36 = 64). Each loan is 0.8 of the last ("shrink by a fifth") OK. Multiplier 1 / 0.2 = 5 OK.
- A06: 1 / 0.03 = 33.33 OK.
- M3 = 4,185,446 + 3,585,981 + 24,387,268 + 122,607 = 32,281,302 (matches wss). Currency 12.97% of M3 OK.
- A09: demand + time deposits = 3,585,981 + 24,387,268 = 27,973,249. 4,185,446 / 27,973,249 = 0.14962 ("about fifteen paise per rupee" OK, but only on this denominator, see b09).
- A14: (0.14962 + 1) / (0.14962 + 0.03) = 1.14962 / 0.17962 = 6.4002. With rounded 0.15: 1.15 / 0.18 = 6.39. "6.4" OK, "about six" is a 6% under-statement.
- Narrow check on b01: M1-type money = currency + demand deposits + other RBI deposits = 4,185,446 + 3,585,981 + 122,607 = 7,894,034; cash share 53.0%. So "most of India's money is not cash" holds for M3 only, not for the narrow measure.
- A11: 5% of 200 = 10; 2% of 200 = 4; 10 - 4 = 6 OK.
- CRR path: 4.50 (to 13 Dec 2024) -> 4.25 (14 Dec 2024) -> 4.00 (28 Dec 2024) -> 3.75 (fortnight from 6 Sep 2025) -> 3.50 (4 Oct) -> 3.25 (1 Nov) -> 3.00 (29 Nov 2025). Six moves from 4.5 to 3.0, of which four (of 25 bp) are the 2025 ones.
